# 한국 PG·결제 생태계 부록

> 수수료·정책·법령은 2025~2026년 조사 기준이며 협상·개정으로 변동된다. 계약 전 PG 영업 견적과 공식 고지로 반드시 재확인. "확인 필요" 표기는 특히 그렇다.

## 1. PG 지형도

국내 PG 150여 개 중 **KG이니시스, NHN KCP, 토스페이먼츠, 나이스페이먼츠** 상위 4개사가 시장 65~70% 점유. 나이스페이먼츠는 2025.10 나이스정보통신과 재합병(PG·VAN 통합) — 계약 시 최신 법인명 확인.

| PG | 카드 수수료(신규 기준, 확인 필요) | 강점 | 적합 |
|---|---|---|---|
| 토스페이먼츠 | ~3.4% + 연 관리비 ~11만원 | 압도적 DX(문서/SDK), 세련된 결제창 | 스타트업, 빠른 개발 |
| KG이니시스 | 3.2~3.5% | 최다 가맹점, 대규모 안정성 | 대형 커머스 |
| NHN KCP | 해외카드 특화 요율 별도 | 해외카드 안정성, USD 정산 | 해외 매출 비중 높은 서비스 |
| 나이스페이먼츠 | ~3.2%, 연 관리비 면제 사례 | 초기비용 최소, 온·오프라인(VAN) 통합 | 초기 스타트업, 오프라인 병행 |

- 일반 요율 레인지: 카드 3.2~3.5%, 계좌이체 1.8~2%, 가상계좌 건당 300~400원, 휴대폰 6~9%, 간편결제 3.2~3.5%.
- 여전법 우대수수료(연매출 기반 하한): 신용 0.4~1.45%, 체크 0.15~1.15% (2026 상반기 공고 기준) — 카드사-가맹점 하한이며 PG 수수료는 별도로 얹힘.
- 정산주기 통상 D+3~D+7 영업일.

### 게이트웨이(포트원) vs 단일 PG 직연동

| 축 | 포트원(멀티 PG) | 단일 PG 직연동 |
|---|---|---|
| 개발 | 통합 API 1회로 다수 PG/빌링 지원 | PG마다 개별 연동 |
| 수수료 | 포트원 이용료 + PG 수수료. 거래 데이터 기반 수수료 비딩 협상력 | PG 수수료만, 단 신생사는 협상력 약함 |
| 장애 | 스마트 라우팅으로 트래픽 분산 | 해당 PG 장애 = 결제 전면 중단 |
| 락인 | 낮음(PG 교체 = 설정) | 높음(교체 = 재개발) |

**권장**: 시드~시리즈A는 게이트웨이로 시작 → 거래량·협상력 확보 후 직연동 전환 검토.

### 심사/계약 절차
사업자등록증 + 통신판매업 신고 + 서비스 URL 심사(개인정보처리방침·약관·환불정책 명시, 규제 업종 체크) + 정산계좌. 간편결제 직연동(네이버페이 결제형 등)은 별도 심사 — 자체 환불 로직 있으면 결제형 입점 불가 등 제약. 호스팅사(카페24 등) 사용 시 지원 결제사 사전 확인.

### 간편결제: PG 경유 vs 직연동
- PG 경유: 계약·정산·심사 단일화, 관리 편함, 수수료는 PG 마진만큼 상승.
- 직연동: 수수료 절감 가능하나 별도 심사·정산·웹훅 로직 — 운영 부담 증가. 카카오페이/토스페이 직연동 조건은 파트너센터 문의 필요.

## 2. 결제 수단별 특성과 구현 함정

| 수단 | 특성 | 함정 |
|---|---|---|
| 카드 | 인증→승인→매입, 3%대 | 무이자할부는 별도 계약, 부분/전체 취소 API 차이 |
| 가상계좌 | 건당 정액, 입금이 비동기 | **입금통지 웹훅이 핵심** — 폴링 백업 없으면 상태 불일치. 입금기한 초과 자동취소 로직 필수. **부분취소 불가** |
| 계좌이체 | 수수료 낮음(1.8~2%), 즉시 출금 | **자동환불 미지원** — 별도 환불 프로세스. 오픈뱅킹 1일 한도 1천만원(신규 3일간 300만원) |
| 휴대폰 소액결제 | 수수료 6~9%, 정보이용료 월 100만원 한도 | 고객 통신요금 미납 시 정산 보류 — 미납 리스크가 가맹점에 전이 |
| 간편결제 | PG 경유 시 3.2~3.5% | **빌링(정기결제) 대부분 미지원**, 각 사 UI 가이드 준수 의무 |
| 애플/삼성페이 | 카드사 부담 수수료 구조 | 카드사별 지원 현황 변동 잦음, 웹결제 지원 여부 PG별 상이 — 사전 확인 |
| 해외카드 | 기존 가맹점에 "해외카드 특약" + 별도 MID | 토스페이먼츠는 KRW 정산만. USD 정산 필요 시 NHN KCP·엑심베이·페이레터·페이먼트월. 정산 = 거래액 − 수수료 − VAT(수수료의 10%) |

## 3. 정기결제(빌링)

- **빌링키**: 카드정보 대체 암호화 토큰. 발급 방식 2가지 — 결제창 방식(권장) / API 방식(카드정보 직접 전달, PCI 부담이 가맹점으로 이전되므로 특별한 사유 없으면 비권장).
- 빌링키는 출금 권한을 가진 민감정보 — **평문 저장 금지, 암호화 저장**.
- **국내 제약**: 카카오페이·네이버페이·토스페이 등 간편결제는 대부분 빌링 미지원 — 구독 UX는 카드 중심으로 설계. PG가 빌링키 발급 목적을 심사하며 구독형이 아니면 승인이 까다로울 수 있음.
- **카드 만료/재발급**: 빌링키 "갱신" 개념이 없다 — 새 카드로 재발급. 구독당 활성 빌링키 1개 유지 로직과 "만료 임박 알림 → 결제수단 업데이트" 플로우를 직접 구현해야 함.
- **dunning**: 국내 PG엔 Stripe Billing급 dunning 엔진이 기본 내장되지 않은 경우가 많음 — 재시도 스케줄러(1·3·7일 시차) + 실패 알림(SMS/푸시/메일) + 결제수단 업데이트 유도를 가맹점이 직접 구현.

## 4. 인앱결제 vs 웹결제

| 방식 | 수수료 |
|---|---|
| PG 웹결제 | ~3%대 |
| 인앱결제 기본 | 30% (정책 유동 — 구글 인하 발표 등 수시 재확인) |
| 인앱결제 소규모(연 $1M 미만) | 15% |
| 제3자결제 + Apple | 26% + PG 수수료 |
| 제3자결제 + Google | (기본 − 4%p) + PG 수수료 |

- 원칙: 순수 디지털 콘텐츠/서비스는 인앱결제 강제 대상. 실물 배송·O2O는 PG 웹결제 가능.
- 제3자결제는 26% + PG 수수료라 실익이 작다 — 국내 실제 패턴: 콘텐츠 앱은 인앱 유지(+소규모 15% 활용), 대형 앱만 제3자결제, 실물 연계는 처음부터 웹결제.
- 아웃링크 유도는 심사 반려 리스크. 한국 전용 바이너리/결제 UI 분기가 실무 패턴.
- 인앱결제 강제방지법 관련 과징금·정책은 유동적 — 구현 시점에 Play Console/App Store Connect 공식 고지 재확인.

## 5. 규제/컴플라이언스

- **전자금융거래법 개정 (2025.11 통과, 2026.12.17 시행)**: PG 정산자금 외부관리(신탁/예치/보험) 의무화 — 시행 후 60%→80%→100% 단계 적용. PG 선정 시 준수 여부 = 정산 지연·도산 리스크 지표. 통신판매중개의 부수적 정산은 적용 제외 가능성(시행령 확인 필요).
- **PG업 등록**: 제3자 간 대금 정산을 대행하면 원칙적으로 금융위 등록 대상. 2차 PG(단순 중개, 정산 미관여)는 예외 가능 — 경계가 분쟁 포인트이므로 자체 정산 모델은 법무 검토 필수.
- **카드정보 비보관**: 가맹점은 카드번호/CVC/유효기간 자체 저장 금지. 예외는 PCI-DSS + 자체 FDS + 재해복구 + 자기자본 400억 이상 — 스타트업은 해당 없음, PCI 부담은 PG가 진다. 가맹점 최소 준수: 카드정보 미저장, HTTPS, 취약점 관리.
- **청약철회/환불**: 철회 7일(서면 수령 기준), 환불 3영업일 내 — 워크플로우에 기한 자동화.
- **현금영수증**: 의무발행업종은 10만원 이상 현금거래 시 요청 없어도 발급. 미발급 1차 5% 가산세, 2차 +20% 과태료. B2B는 세금계산서(전자세금계산서 API/ERP 연동 고려).

## 6. 해외 결제

- **Stripe**: 한국 사업자 직접 개설 불가(2026 기준 미지원국). 해외 법인 계정으로 한국 고객 결제 수취는 가능.
- **한국 법인 → 해외 고객 판매 옵션**:

| 옵션 | 수수료(실효, 확인 필요) | 세금 | 비고 |
|---|---|---|---|
| Paddle | 5% + $0.50 (~7%) | MoR 대행 | $5M+ ARR급 SaaS 적합 |
| Lemon Squeezy | 5% + $0.50 + 부가 (~7%대) | MoR 대행 | Stripe 인수 후 로드맵 불확실 — 확인 필요 |
| Polar/Dodo/Creem 등 신흥 MoR | 3.9~4% + $0.40대 | MoR 대행 | 초기 검증용, 성숙도 낮음 |
| 해외법인 + Stripe | 2.9% + $0.30 (+Tax ~0.5%) | 직접 신고 | 설립·유지비 연 $1,000~2,500, 손익분기 연매출 ~1.4억원 추정 |

- 권장 경로: MRR ~$5K까지 신흥 MoR로 빠른 검증 → $30K~100K 구간에서 해외법인+Stripe 검토. 전환 시 카드정보 미이전으로 구독자 5~15% 이탈 가능성.
- 국내에서 해외카드 받기: 국내 PG에 해외카드 특약 신청(2절 참조).
